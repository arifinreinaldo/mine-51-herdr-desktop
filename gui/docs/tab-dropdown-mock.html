What changed and why

  • Purpose is stated: header "Tabs · 7" says it is the list of every tab; it exists because they no longer fit the strip.
  • Where you are: checkmark + bold name on the active tab. The strip already hides the active tab's dot, so the menu shows none for it.
  • Dots only when they carry news: idle tabs get no dot (a hollow circle on every row is noise). Blocked / working / done keep their shape + colour, and the right column spells the state in words, so colour is never the only signal.
  • Right column = the reason to look: blocked age ("needs input · 4m") or pane count. Muted, tabular numbers, so it scans.
  • Name stays next to its marker; long names truncate with an ellipsis. Rows 30px, 300px wide, list scrolls past ~420px.
  • Footer "New tab": when "+" is pinned far right the list is the natural place for it too, and it teaches the shortcut.
  • Not in the mock: per-tab Ctrl+1…9 hints and a filter box. Add the filter only if users regularly hold 15+ tabs.
